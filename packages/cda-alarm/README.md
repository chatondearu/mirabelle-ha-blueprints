# CDA Alarm

Home Assistant custom integration — single `alarm_control_panel` source of truth
with unified codes, Frient KEPZB-110 (ZHA) keypad binding, and `open_sensors`
for Mirabelle alarm blueprints.

**Full guide:** [docs/cda-alarm.md](../../docs/cda-alarm.md) (install, configuration,
migration from Alarmo, troubleshooting).

**Quick install:** copy `custom_components/cda_alarm` to your HA
`config/custom_components/cda_alarm`, restart, then add **CDA Alarm** in
**Settings → Devices & services**.
